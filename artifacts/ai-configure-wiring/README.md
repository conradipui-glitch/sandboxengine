# Приёмка зоны: кнопка «Настроить подключение» доводит до формы подключения

## Что было сломано

В панели ИИ-помощника (`apps/studio/src/ai-panel.ts`) кнопка
`data-action="ai-configure"` («Настроить подключение») вызывала `openConfigure()`,
который отправлял всплывающее `CustomEvent(AI_PANEL_CONFIGURE_EVENT = "ai-panel:configure")`
из корня панели. Слушателя этого события в продукте не было — нажатие не давало
ни изменения DOM, ни запроса, ни перехода.

## Что сделано

1. `apps/studio/src/app.ts` — в конструкторе приложения на корень навешен ровно
   один слушатель `AI_PANEL_CONFIGURE_EVENT` (и снимается в `destroy()`).
   Обработчик `onAiConfigureRequest` открывает настоящий блок подключения
   «Подключение ИИ-помощника» (`.provider-settings` / `#provider-form` из
   `apps/studio/index.html`, который оживляет `apps/studio/src/provider-settings.ts`),
   ставит фокус в первое поле формы и подтверждает открытие через `preventDefault`.
   Ни запросов, ни полной перерисовки оболочки из обработчика нет.
2. `apps/studio/src/ai-panel.ts` — событие стало `cancelable`, а нажатие, которое
   никто не подтвердил, больше не молчит: панель показывает честное объяснение
   `data-ai-configure-notice` с действиями («Настроить подключение», «Проверить снова»).

## Доказательства

`model`, `credential`) и кнопка «Сохранить подключение» на месте, фокус — в первом
поле, новых запросов нет, панель осталась в том же хосте, слушатель ровно один и
снимается вместе с приложением. Отдельные тесты: три нажатия подряд не плодят
слушателей и запросов; без блока подключения в оболочке панель показывает
`data-ai-configure-notice`; панель как модуль без слушателя тоже не молчит.

## Что осталось непроверенным

- Поведение при не-владельце проекта: правами управляет `provider-settings.ts`
  (для не-владельца он оставляет только строку статуса и убирает поля). Открытие
  блока проверено, скрытие полей в этой зоне не перепроверялось.
- Живой запрос к настоящему провайдеру: на стенде провайдер не настроен, поэтому
  проверялся только путь «подключение не настроено → форма открывается».
