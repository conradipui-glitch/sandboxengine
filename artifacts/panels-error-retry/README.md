На стенде тот же дефект ранее замерялся как ~650 запросов за 4 с; здесь число ниже,
потому что прогон идёт через два локальных прокси (браузер → прокси-счётчик → Studio → Control).

Как устроено измерение: перед Studio поднимается собственный прокси-счётчик
(`127.0.0.1:4199` → Studio `127.0.0.1:4200`). Он считает реальные HTTP-запросы и по флагу
отвечает 503 — намеренно недоступный эндпоинт без правок продукта. Числа сверяются с
запросами, которые видит сам браузер (`Network.requestWillBeSent`).
