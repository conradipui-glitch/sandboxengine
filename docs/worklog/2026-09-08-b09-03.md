## Implementation

### Draft history, restore, comparison and reference safety

- Reused immutable draft snapshots as the durable version-history source; no second history store.
- Added bounded deterministic history paging with Memory/SQLite parity.
- Added deterministic revision comparison for title/entry location/block add-remove-replace changes.
- Added restore-old-as-new-revision with exact `sourceRevision`, expected-current `baseRevision`, server-derived request identity and durable idempotency.
- Added typed reference analysis and shared deletion semantics; actual `block.remove` always rechecks current authoritative draft.
- Added regression proving stale green deletion preflight cannot authorize a later now-referenced deletion.

### Portability

- Added project-scoped clone with deterministic block-ID remap and supported typed reference rewrite.
- Clone pins its source revision for retries, is idempotent and never aliases/mutates source draft history/releases/playtests.
- Added deterministic inert `.lhquest.zip` export bound to an exact draft revision or exact immutable release.
- Export package has explicit format/schema metadata and SHA-256 file hashes and excludes Control/provider/Runtime/player secret/state material.
- Added hostile-input bounded archive parser and atomic/idempotent new-draft import.
- Import rejects traversal/absolute/NUL/normalized duplicate/symlink-like paths, unsupported compression/content/schema/plugins, excessive size/count/member limits, hash mismatch, executable/HTML-like content, forbidden secret sections and invalid references.
- Failed import creates no partial quest/assets and never publishes automatically.

- Added explicit restore prepare/confirm intent with stable idempotency key and stale-base fail-closed UX.
- Added immutable release build intent and exact publish report without moving publication pointer.
- Added owner-only publish/rollback confirmation tied to expected-current CAS and receipt-gated wording.
- Completed Access UI over B09-01 session/member/role APIs without displaying secrets.
- Added persisted playtest evidence surface with exact frozen playtest identity and bounded Runtime sessions/completed operations/turn boundaries.
- Added Studio clone/exact export/safe import UX as a thin client over server contracts; browser does not parse/rebuild archives.
- Added dangerous deletion preflight UI that shows concrete typed referring block/path and only offers confirm for an exact green revision; actual mutation still rechecks server truth.

### Persisted playtest evidence

- Added a read-only Runtime trace adapter over existing durable `sessions`, `operations` and `turns` tables.
- Trace filters by exact frozen-playtest runtime identity and includes only completed persisted evidence.
- Guest credentials, idempotency keys, request hashes and lease/fencing internals are not exposed.
- Control derives the trace release identity from the authoritative frozen playtest record; browser cannot select another release.
- Studio E2E proves frozen playtest → Runtime HTTP action → SQLite persistence → Control trace → Studio renderer without replaying gameplay/AI.
