## Реализовано

### `@living-history/player`

- новый package boundary;
- deterministic `bootstrapFrozenPlaytest`;
- initial `WorldState` только из frozen snapshot;
- bounded paint definitions из frozen action blocks;
- broken/unsupported playtest fail closed;
- `RuntimePlayerClient` для create/refresh/action/reset;
- Player package не импортирует Core/Control/SQLite/storage.

### Causal Runtime path

Найден B04 compatibility hardcode в action executor: fixed `blue_paint`, cost=1, 300s.

Для authored path добавлен `createCoreExplicitActionExecutorForDefinition(definition)`. Definition приходит из frozen playtest и используется существующим Core resolver. Старый factory сохранён только для B04 minimal fixture.

Канонический E2E:

- P1 cost=1, initial resource=2, request2 → executed2 / 600s;
- reset P1 → тот же initial state/rules;
- draft edit cost=2;
- P1 не меняется;
- P2 cost=2, request2 → partial1 / 300s;
- P1/P2 hashes различаются;
- idempotent retry не запускает Core второй раз.

### Player UI

Создан `apps/player`:

- quest/playtest header;
- нейтральная scene surface;
- safe resource projection;
- game time;
- integer quantity;
- `Рисовать`;
- executed/partial/blocked result;
- requested/completed/duration из server response;
- Reset;
- responsive layout.

Browser не получает/не вычисляет `resourceUnitsPerUnit` и не получает raw compiled artifact/content hashes.

### Real `dev:player`

`LH_PLAYTEST_ID` выбирает exact durable frozen playtest из SQLite ControlStore.

Process:

1. loads frozen record;
2. bootstraps template/state/definition;
3. starts loopback Runtime + SQLite guest/session storage;
4. binds executor to frozen definition;
5. starts loopback Player proxy/surface.

Process regression создаёт настоящий cost=2 frozen playtest, запускает emitted `apps/player/dist/src/main.js`, выполняет action → partial1/300s и reset → initial resource/time.

### Studio → frozen playtest bridge

Studio Control client теперь умеет вызывать существующий create-playtest endpoint.

После exact-current valid validation UI:

- предлагает `Создать frozen playtest`;
- показывает playtest ID;
- показывает PowerShell/macOS/Linux команды `npm run dev:player`;
- после последующего draft edit старый playtest помечается как previous frozen revision и не переписывается.

Regression: freeze P1 cost=1 → edit draft cost=2 → persisted P1 всё ещё cost=1 → validate/freeze P2 → P2 cost=2.

### Studio process audit

Во время B05-03 аудита найден реальный B05-02 gap: emitted `apps/studio/dist/src/main.js` имел неверную глубину static relative import к `apps/server/dist/control-server.js`. Модульные Studio tests его не ловили.

Исправлено dynamic runtime import относительно emitted module. Добавлен постоянный process smoke:

- spawn real Studio main;
- GET Studio `/`;
- GET proxied `/control/v1/projects`.

Теперь и Studio, и Player проверяются как реальные runnable processes.
