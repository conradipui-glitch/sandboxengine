## Сделано

- Добавлены JSON Schema Draft 2020-12 v1.0 для `Effect`, `ActionResult`, минимального `WorldState`, `SceneFrame`, `PresentationPlan`.
- Добавлены стабильные schema IDs и общий `CONTRACT_SCHEMA_VERSION = "1.0"`.
- В v1.0 неизвестные поля отклоняются (`additionalProperties: false`); несовместимая версия отклоняется.
- `ActionResultEnvelope` и Effect стали явно versioned; Core builder добавляет версии автоматически.
- Добавлены TypeScript DTO `WorldState`, `SceneFrame`, `PresentationPlan` и публичные exports.
- Добавлен semantic reference layer для тех ограничений, которые JSON Schema не выражает как membership: locations/holders и `dialogue.show.lineId`.
- Добавлены положительные и отрицательные fixtures на status/version/type/reference.
- Добавлен Ajv `8.17.1`; lockfile проверен реальным `npm ci` в GitHub Actions.
- Создана следующая bounded-карточка `B01-03-authoring-schemas.md`, чтобы не перепрыгивать к B02 до завершения общего B01.

## Архитектурная граница

JSON Schema подтверждает форму значения. Наличие referenced ID в другом объекте подтверждает semantic validation. Эти две проверки намеренно не смешиваются. Asset/release references, которых ещё нет в текущем контрактном слое, не достраивались по догадке.

`PresentationPlan` пока содержит только узлы с конкретно заданными аргументами в спецификации первого сквозного примера. Другие перечисленные в ТЗ presentation commands остаются planned, а не advertised capability.
