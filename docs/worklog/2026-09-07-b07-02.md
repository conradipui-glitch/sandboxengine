## Implementation

Created infrastructure-only `@living-history/assets` and added it to workspace/typecheck/root verify.

Public flow:

`bytes → inspectAssetBytes → trusted MIME/dimensions/duration → SHA-256 → AssetManifestV2 → LocalAssetStore.put → exact LocalAssetStore.read(assetId, hash)`.

No HTTP upload endpoint or Studio/Player renderer was added.

### Supported bounded profiles

- PNG;
- static WebP;
- JPEG;
- integer PCM WAV;
- Ogg Vorbis;
- MP3 Layer III.

Rejected explicitly: SVG/XML/HTML/script/unknown bytes, unsupported codec/profile, claimed MIME mismatch and filename extension mismatch.

### Storage/registry

- object identity is SHA-256 over actual full bytes;
- object path derives only from trusted hash;
- logical registry path hashes validated assetId and contains exact content hash;
- original filename is display metadata only;
- temporary exclusive write + hard-link create-if-absent;
- no overwrite;
- same content deduplicates after integrity verification;
- same logical assetId with different bytes creates a second immutable record;
- old exact record remains readable;
- read rechecks byte length + SHA-256;
- missing/corrupt record/blob is explicit, no version substitution.

## Hardening audit after first green

Found real robustness gaps before acceptance:

1. WebP first-chunk declared length was not fully bounded.
2. PNG metadata parser did not require final IEND.
3. JPEG could accept bytes after the nominal image end.
4. Metadata limits were partly fixed constants instead of explicit configurable-downward limits.
5. Registry directory derivation used slash slicing instead of platform path semantics.
6. WAV duration initially trusted declared byteRate more than necessary.
7. Animated WebP would introduce an independent animation timeline inside an image asset.
8. The initial monolithic source mixed inspection/storage/ingest responsibilities.

Hardening commits made parsers fail closed, moved to `dirname`, copied bytes before async storage, bounded metadata limits to canonical schema maxima, and added targeted regressions.

Hardening head before refactor: `20d2f33e5b9dc3d4855f1927b3c93cda137b6849`.
