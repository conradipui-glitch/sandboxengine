## Goal

Wire B07 presentation contracts/assets/executor into the real Runtime/HTTP/browser Player path without moving gameplay authority out of Core/Runtime.

## Implemented

### Runtime / persistence

- added `PresentationRuntimeStorage` decorator;
- presentation is attached immediately before the existing atomic commit;
- candidate WorldState and TurnRecord are passed through unchanged;
- committed public response persists `SceneFrameV2` and optional validated `PresentationPlanV2`;
- idempotent retry returns the exact stored presentation identity;
- no-turn outcomes remain presentation-free.

### Reference presentation producer

- deterministic frozen-template/revision-based frame builder;
- one-turn bounded actor-expression transition for the reference path;
- catalog/reference/convergence validation before attaching a plan;
- invalid transition degrades to frame-only rather than widening authority.

### Player transport

- optional presentation parser added to `RuntimePlayerClient`;
- malformed/authority-widened presentation is discarded independently from valid gameplay result;
- session handle keeps confirmed presentation frame and last committed operation id;
- resume restores persisted frame from the stored operation without replaying its historical plan.

### Browser surface

- real published `PresentationExecutor` is imported into the browser;
- minimal DOM renderer supports final frame/background/actors/items/dialogue/overlays/audio/wait primitives;
- SceneFrame/Plan text uses DOM/text APIs, not presentation-controlled `innerHTML`;
- skip control and `prefers-reduced-motion` are wired;
- pagehide/reset cancel presentation work only;
- image decode and audio-start errors surface to executor fallback.

### Asset delivery

- exact `assetId + hash` route;
- guest credential required;
- request is scoped to the same frozen quest/release;
- trusted MIME is taken from registered manifest/store;
- wrong hash, missing asset, corruption and traversal fail explicitly/no mutable-version fallback.
