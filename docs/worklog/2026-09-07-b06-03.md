## Цель slice

Добавить presentation-stage после Core: bounded `FactPacket` → narrator/validator → deterministic fallback → один persisted public response → один `commitTurn`.

Narrator не получает gameplay authority, полный `WorldState` или право отменять уже рассчитанный Core action.

## AI layer

Добавлены:

- versioned `FactPacket`;
- `NarrativeProfileId`: `strict` / `expressive`;
- `ModelNarrator` поверх существующего `ModelProvider`;
- максимум 2 narrator attempts, repair входит в лимит;
- exact output shape `summary/dialogue/observationRefs`;
- speaker/observation allowlists;
- deterministic fallback для `executed` / `partial` / `blocked`;
- T13/T14 regressions.

Authority fields вроде `statePatch`, `effects`, action mutation, hidden asset/observation/speaker IDs и extra keys отклоняются.

## Первый CI и реальное расхождение

Первый PR CI `34058185395` на раннем AI-layer head дошёл до `test:ai` и дал 3 failures при green contracts/core.

Причина была не в narrator architecture: тесты передавали абсолютный `deadlineAtMs = 10_000`, тогда как `ModelNarrator` честно сравнивает deadline с реальным `Date.now()`. Поэтому provider не вызывался ни разу, valid output уходил в fallback, а T13 call-count ожидания не проверяли intended retry semantics.

Commit `495386af68ddc0fbe036806f4af148a57fb0011a` заменил ложный абсолютный timestamp на `Date.now() + 10_000`; отдельный expired case сохранил deadline `0`.

Это исправило test harness, не production deadline logic.

## Runtime integration

Commit `f20c2984af06ccf918dae558e9a835b7d6997c0c`:

- добавлен единственный `buildFactPacket` из before-state + Core-calculated execution;
- packet содержит action result, clock delta, изменившиеся public resources, bounded speaker IDs;
- packet не содержит full state, min/max, items, contentHash, storage/fencing metadata;
- `buildCommittedPublicResponse` получил optional bounded narrative.

Commit `31ff34edc886cc167ae17e1b401ba4060083e2d5`:

- optional `Narrator` и narrative profile подключены к Runtime;
- после successful claim создаётся один absolute AI deadline;
- free-text intent и narrator получают тот же deadline timestamp;
- Core выполняется до narrator;
- narrator success/fallback включается в public response до `commitTurn`;
- narrator exception переводится в deterministic fallback;
- narrator failure после Core не становится `ACTION_EXECUTION_FAILED`;
- narrator-disabled Runtime сохраняет старый public payload.

## Runtime T13/T14 evidence

`apps/server/test/runtime-narrative.test.mjs` закрепляет:

- unknown speaker + illegal `statePatch` после двух attempts → deterministic fallback;
- fallback всё равно приводит к ровно одному committed Core turn;
- idempotent retry возвращает persisted narrative и не повторяет narrator/Core;
- valid narrator не меняет structured action, clock/resource result и не вызывает Core второй раз;
- text intent и narrator используют один exact absolute deadline;
- narrator input не содержит resource min/max, item `sealed_letter`, contentHash, fencingToken/requestHash;
- public narrative не содержит provider evidence/diagnostics.

## Player compatibility

`RuntimePlayerClient` принимает optional narrative:

- без narrator `result.narrative === null`, старый Runtime остаётся валиден;
- при наличии narrator наружу проходят только profile/source/summary/dialogue/observationRefs;
- provider evidence не публикуется;
- narrative deep-frozen и exact-shape validated.

Player UI отображает narrative внутри существующего result surface с HTML escaping. Числовые action/resource/time данные продолжают приходить только из structured `action`/`playerView`; client-side simulation не добавлена.
