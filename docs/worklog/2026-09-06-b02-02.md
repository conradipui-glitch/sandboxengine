# 2026-09-06 — B02-02 explicit action resolver

## Сделано

- Добавлен strict `CalculatedAction` v1.0, отдельный от public B01 `ActionResult` v1.0.
- Первый calculated action type — `core.paint`.
- `resolvePaintAction` принимает explicit `ResolvedIntent`, definition и authoritative `WorldState`; свободный текст не разбирает.
- Resolver сам считает completed units, duration и `resource.change` effect.
- Реализованы `executed`, `partial`, `blocked` для paint resource policy.
- Рассчитанный effect проходит `tryApplyEffectBatch`; duration не двигает clock/revision.
- Generated capabilities/SKILL показывают `core.paint`.
- ADR 0004 фиксирует границу `CalculatedAction` vs transport `ActionResult`.
