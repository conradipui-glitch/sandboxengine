## Решение по B01

Общий B01 принят в текущем schema-first объёме. Доказаны: канонические схемы и DTO boundary, semantic references, два независимых fixture-пакета, compile skeleton, deterministic content hash, readiness registry и воспроизводимый agent kit. Это не означает готовый Runtime API или исполняемую игру.

TypeScript DTO пока остаются ручными schema-first экспортами, проверяемыми общими fixtures/parity tests. Отдельный генератор TypeScript-кода не вводится без независимого потребителя; при дальнейшем несовместимом изменении schema требуется явная versioning/compatibility запись.
