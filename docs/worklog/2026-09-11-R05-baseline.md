## 4. Окруженческие причины (отделены от дефектов кода)

Падений, вызванных окружением, НЕТ — все команды вернули exit 0. Окруженческие *ограничения*:

1. **Pinned Node обязателен.** `engines.node >=24.19.0 <25`. Системный Node 22.x даёт ложное падение
   C17 (`apps/studio/test/correction-acceptance.test.mjs:209-213`):
   `assert.equal(process.version.startsWith("v24."), true);`
   Под pinned `v24.19.0` C17 проходит. Это ровно тот класс ложных падений, что описан в задаче.
2. **C18 окруженчески пропущен** (`correction-acceptance.test.mjs:215-218`): требует
   `CORRECTION_VPS_URL` и сетевой доступ к VPS; без переменной — SKIP, не fail.
3. **drill:startup-shutdown на win32** возвращает `result:"skip"`: `child.kill()` не доставляет
   graceful-сигнал на Windows; проверка health/Control-пробы всё равно выполнилась
   (`/healthz:200`, `/control/v1/agent-kit:200`, `sqliteCreated:true`). Авторитетный гейт — POSIX CI.
4. **eval:ai без секретов** возвращает `status:"not_configured"`
   (`reason:"LHE_EVAL_API_KEY and LHE_EVAL_MODEL are required for explicit live eval"`), live-вызов не делался.
5. Отсутствующих бинарей, сетевых отказов и ошибок установки не было: `npm ci` exit 0, 14 пакетов, 0 уязвимостей.

## 5. Что НЕЛЬЗЯ проверить локально

1. **C18 exact-SHA VPS smoke** — требует задеплоенного на VPS exact-SHA и сетевого доступа к нему
   (env `CORRECTION_VPS_URL`). Локально пропускается.
2. **`npm run eval:ai` live** — требует платных провайдерских креденшелов
   (`LHE_EVAL_API_KEY`, `LHE_EVAL_MODEL`, опц. `LHE_EVAL_BASE_URL`). RUNBOOK §10 явно выносит это из
   релизной верификации. Без ключей — только `not_configured`.
3. **drill:startup-shutdown graceful-exit** — на Windows недоказуем (`result:"skip"`); нужен POSIX CI/хост.
4. **Live Telegram-гейт и ролевые проверки C18 editor/viewer/read-only** — требуют отдельных
   Telegram-аккаунтов на гейте (зафиксировано в `docs/HANDOFF.md`), локально недоступны.
5. **Authenticated Control вне loopback и браузерный проход глазами игрока** — требуют
   развёрнутого окружения/секретов; в эту базовую линию не входят.
