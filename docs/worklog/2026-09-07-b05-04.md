## Реализовано

### Static persistent Help

Добавлен отдельный `apps/studio/src/onboarding.ts`, загружаемый рядом с существующим Studio.

Help доступна через постоянную кнопку `? Справка` независимо от выбранного проекта/квеста и содержит только реально реализованный B05 vocabulary:

- project/quest;
- resource;
- `core.paint`;
- save/revision/conflict;
- validation;
- frozen playtest;
- local Player launch;
- Reset semantics.

Контент хранится в репозитории и не генерируется моделью.

### Repeatable deterministic tour

Восемь шагов:

1. projects/quests navigation;
2. resource;
3. paint action/cost;
4. revision/conflict;
5. validation;
6. frozen playtest;
7. Player launch + Reset meaning;
8. persistent Help/replay.

Есть Next, Back, Skip, explicit completion и `Повторить обучение` из Help.

Если нужный quest/validation/playtest element ещё отсутствует, tour объясняет prerequisite и не создаёт synthetic data.

### UI-only preference

`completed` / `skipped` может храниться только в localStorage.

Storage failure не ломает Studio: preference read/write fail closed к `null/false`, и tour можно показать снова.

Completion flag не связан с Control, draft, Runtime или permissions.

### Accessibility / interaction

- Help имеет accessible dialog title;
- tour имеет dialog title;
- Escape закрывает открытый Help/tour;
- focus возвращается на Help trigger;
- Next/Back — обычные keyboard-accessible buttons;
- mobile layout держит controls доступными;
- после закрытия DOM overlay/highlight удаляются и authoring UI не блокируется.
