# Worklog — B03-03

Дата: 2026-09-06

## Цель

Добавить bounded task/deadline/terminal/RNG слой поверх принятых B03-01/02 без storage, HTTP, wall-clock или LLM.

## Реализовано

- strict `ScheduledTask:1.0`, kind `core.task`;
- pure `projectTaskEvents(state, task)` с actor/time validation, stable start/completion IDs и deterministic projection;
- strict `ScheduledTerminalEvent:1.0`, kind `core.terminal`;
- pure `projectDeadlineEvent(...)`;
- scheduler union marker/effects/terminal;
- terminal interruption в `applyTimeAdvancePlan`:
  - previous due effects применяются;
  - terminal фиксирует `WorldState.terminal`;
  - clock останавливается на terminal time;
  - revision растёт один раз;
  - later due events становятся `unprocessedEvents`;
- `already_terminal` policy для нового normal interval;
- functional deterministic RNG `lcg32-v1` с explicit immutable state и provenance;
- generated capabilities: `core.effects`, `core.marker`, `core.terminal`; scheduled task `core.task`;
- schema IDs task/terminal отдельны, существующие strict event contracts не widened.

## Каноническая сверка общего B03

B03-03 принят по собственной карточке, но общий B03 пока **не принят**. Сверка с `docs/SPECIFICATION.md` выявила конкретные незакрытые части:

- T05 требует фактического возвращения NPC на 900-й секунде внутри interval до 2400 и проверки, что последующие шаги видят новое location-state; текущие GameplayEffect не умеют перемещать entity.
- T06 требует completion ровно при deadline с однозначным same-time order и явного crossing-midnight regression.
- T08 требует dynamic spawned event + общий step/event budget; текущий planner ограничивает статическую due queue, но не обрабатывает generated child events.
- B03 acceptance требует одинаковый plan+seed → одинаковые effects и hash; RNG есть, но scheduler replay/hash ещё не оформлен.

Эти четыре пункта вынесены в bounded B03-04 вместо разрастания B03-03.
