# Worklog — 2026-09-06 — B03-01

## Цель

Начать B03 минимальным scheduler-planning слоем без persistence и без применения event effects.

## Реализовано

- strict `ScheduledEvent` v1.0;
- первый bounded kind `core.marker`;
- safe-integer `atElapsedSeconds` и `order`;
- provenance через `sourceId`;
- чистый `planTimeAdvance`;
- inclusive boundary `[start,end]`;
- deterministic sort `time → order → eventId`;
- duplicate/past/invalid events как explicit failures;
- future events остаются pending;
- duration=0 не затрагивает future event;
- safe clock overflow check;
- bounded max-events с whole-plan failure;
- generated agent capabilities/schema index обновлены.

## Проверка риска

Опорная регрессия: state clock=0, action duration=600 sec, event at=300 sec. Plan содержит event в `dueEvents`, end=600, при этом authoritative state остаётся clock=0.

Также проверено:

- перестановка входного массива не меняет результат;
- одинаковый timestamp разрешается `order`, затем `eventId`;
- event ровно в `start` и ровно в `end` входит в inclusive plan;
- event после end остаётся pending;
- past event не пропускается молча;
- event limit не возвращает partial plan;
- unsafe duration/options/clock overflow отклоняются;
- event contract не допускает arbitrary effects/code.
