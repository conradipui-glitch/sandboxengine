### Compatible inference adapter / T30 foundation

`OpenAiCompatibleModelProvider` поддерживает bounded Chat Completions subset:

- OpenRouter preset `https://openrouter.ai/api/v1`;
- explicit custom compatible endpoint;
- separate header-only raw credential;
- text / JSON-object profile capability;
- output limit;
- absolute deadline + AbortSignal;
- no internal retries;
- redirect=`error`;
- normalized/sanitized provider errors;
- optional honest usage/model/request ID.

Connection factory использует preset URL либо explicit compatible URL. Connection test подтверждает только реально возвращённую форму и различает `capability_mismatch`.

Endpoint policy блокирует URL credentials/query/fragment, static private/link-local/metadata/reserved targets; HTTP разрешён только explicit loopback dev policy. DNS-aware egress isolation остаётся deployment/transport guard и не объявляется решённой syntactic validation.

### Quota / T31 foundation

OpenRouter adapter:

- `/key` — inference credential;
- `/credits` — только отдельный management credential;
- без management credential account metric = `permission_required` и второго запроса нет;
- real `0` не превращается в unknown;
- unknown numeric = `null`;
- word-period `monthly` не превращается в invented timestamp;
- explicit ISO reset сохраняется в `resetsAt`;
- quota endpoint error даёт metric status=`error`, но не ломает inference provider;
- cache key включает connection/account/credential revision;
- expired available metric становится `stale`.
