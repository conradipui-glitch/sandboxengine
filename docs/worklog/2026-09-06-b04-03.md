# 2026-09-06 — B04-03 Runtime HTTP / guest / PlayerView

## Цель

Завершить общий B04 публичной Runtime transport boundary поверх опубликованных B04-01/B04-02 semantics без LLM, Studio и Florence migration.

## Реализовано

- `apps/server` как отдельный Node TypeScript project.
- Built-in `node:http`, без нового framework/dependency.
- Guest session access отделён от `SessionRecord`/`WorldState`.
- SQLite guest verifier хранится в отдельной access table как SHA-256 hash.
- Deny-by-default `PlayerView` по explicit allowlist.
- Public endpoints:
  - `GET /healthz`;
  - `POST /v1/sessions`;
  - `GET /v1/sessions/{sessionId}`;
  - `POST /v1/sessions/{sessionId}/actions`;
  - `GET /v1/sessions/{sessionId}/operations/{operationId}`.
- Первый bounded action transport — только `core.paint`.
- Server-side canonical SHA-256 request identity.
- Completed retry возвращает persisted response до Core execution.
- 202/409/404/503 transport mapping поверх существующих storage outcomes.
- Public operation projection не раскрывает lease/fencing/request hash.
- Runnable `main.ts` создаёт каталог SQLite при чистом старте.
- `test:server` входит в обязательный `verify`.

## CI итерации

1. Первый gate дошёл до TypeScript и поймал четыре type-boundary ошибки; semantics/tests не ослаблялись.
2. Второй gate дошёл до T15; 3/4 server tests прошли. Единственный fail был ошибкой leak-test: substring `min` совпал с `minimal-paint`.
3. Leak-test переписан на рекурсивную проверку JSON field names.
4. T15 functional gate стал зелёным: 4/4 server tests.
5. Semantic audit добавил hardening regressions:
   - credential hash-at-rest;
   - cross-owner mutation denial;
   - malformed/oversize input до claim;
   - real SQLite lock → HTTP 503 без Core/partial operation.
6. Hardening gate `34038239722` — success.
7. Registry переведён на пять реально работающих Runtime endpoints; planned quests/control не рекламируются.
8. Generator расширен `successStatus`, чтобы session creation публиковалась как 201.
9. Generated docs синхронизированы; publication gate `34039363270` — success.

## Архитектурные решения

- HTTP не пересчитывает gameplay logic.
- Guest credential не является частью мира.
- Player получает projection, не raw state.
- Registry readiness следует реализации/tests, а не плану.
- Сохраняется зарегистрированный `/healthz`; новый `/v1/health` не вводится только ради task wording.

Решение: ADR 0013.
