# 2026-09-06 — B02-01 typed effects и atomicity

## Сделано

- Добавлена отдельная schema/type family `GameplayEffect` v1.0 без несовместимого изменения B01 `Effect` v1.0.
- Первый executable effect — `resource.change` с `resourceId`, integer `delta` и `sourceId`.
- Добавлен `tryApplyEffectBatch` над trial-copy `WorldState`.
- Batch применяется all-or-nothing: failure не возвращает новый state.
- Проверяются missing resource, resource bounds, safe integers, invalid/unsupported effect types и валидность исходного state.
- Исходный state, revision и clock не мутируются.
- Generated capabilities/SKILL показывают `resource.change`; HTTP operations остаются пустыми.
- Версионирование зафиксировано ADR 0003.
