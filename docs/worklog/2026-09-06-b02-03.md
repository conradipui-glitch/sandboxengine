# 2026-09-06 — B02-03 conditions и item transfer

## Цель

Добавить первый общий декларативный язык preconditions и второй базовый gameplay effect, чтобы доказать переносимость Core за пределами `core.paint` и закрыть mixed atomicity T07.

## Сделано

- Добавлен strict `Condition` v1.0:
  - `resource.atLeast`;
  - `entity.at`;
  - `item.heldBy`;
  - `all`;
  - `any`;
  - `not`.
- Добавлен чистый `evaluateCondition` с отдельными failure-кодами для invalid shape и broken references.
- Composite evaluator не скрывает ошибочную ссылку short-circuit'ом.
- В `GameplayEffect` добавлен `item.transfer` с destination `location|holder`.
- `tryApplyEffectBatch` расширен trial-copy предметов и проверками item/holder/location references.
- Смешанные resource+item batches остаются all-or-nothing.
- Добавлены fixtures/schema/parity tests и Core regression tests.
- Generated agent kit расширен `conditionTypes` и `item.transfer`; planned HTTP endpoints не стали available.
- Добавлен ADR 0005.

## Доказанные риски

- `resource.atLeast` на известном ресурсе различает true/false.
- Broken ID не превращается в false.
- Broken child внутри `all` обнаруживается даже после false sibling.
- Valid item transfer не мутирует authoritative input и оставляет item ровно в одной position.
- T07: валидный resource effect перед невалидным item transfer не применяется частично.
