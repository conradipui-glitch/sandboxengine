# ADR-0001: границы отдельного Engine-репозитория

**Статус:** принято для bootstrap, пересматривается только через ADR.

Движок живёт в `conradipui-glitch/sandboxengine`, а действующая игра остаётся отдельным клиентом и источником материала для B00/B11. Начинаем с модульного монолита и npm workspaces: чистые `contracts` и `core` отделены от будущих runtime, Studio и Player. Это даёт переносимость без преждевременного запуска четырёх инфраструктурных реализаций.

Core не импортирует HTTP, React, SQLite, Cloudflare, файловую систему, секреты или prompt-код. Авторский помощник и будущий Builder вызывают те же проверенные операции, а не создают вторую систему изменения данных.
