# ADR-0002: порядок поставки hackathon-MVP

**Статус:** рабочее решение для цели 14 октября 2026 года.

Полная дорожная карта ТЗ остаётся архитектурным планом. Для демонстрационного vertical slice допускается короткий путь: baseline → contracts/core → минимальный runtime → один клиентский маршрут → ограниченный migration adapter → живой плейтест. Авторский помощник, каталог провайдеров и Builder идут после доказанного игрового пути.

Это не разрешение обходить причинность, атомарность, право игрока на собственное решение или честные статусы. Меняется только порядок и объём поставки; статусы B00–B13 обновляются только по фактической приёмке.
