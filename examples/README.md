# Real quest examples

B11 uses this directory for concrete quest packages that exercise the portable Engine without becoming part of Core.

- `florence/` — migration of the real Florence workshop semantics from the pinned legacy source.
- `transfer-desk/` — a materially different lost-property quest proving social request/response, resource pressure and item transfer.

Each package keeps generic contract data (`quest-release.json`, `blocks.json`, `initial-state.json`) separate from example-owned narrative beat data.

Florence source-asset provenance is frozen in `florence/source-assets.json`. Binary copy remains an explicit sub-gate until bytes can be transferred and verified; the repository must not call a path list an ingested asset.
