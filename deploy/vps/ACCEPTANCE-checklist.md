# Приёмка бот-управляемого входа Living History Studio (вживую, с людьми)

Контур: `https://85.137.95.104.sslip.io:8741` → страница входа → бот
**@living_history_gate_bot**. Живую приёмку с реальными людьми автоматика
провести не может (нет доступа к чужим Telegram-аккаунтам) — шаги ниже
выполняются вручную. Автотесты гейта/бота: `node --test deploy/vps/lhc-gate.test.mjs`.

Подготовка: владелец один раз пишет боту `/start` (иначе не получит заявки).
Токен — только на VPS (`/opt/lhc/engine/deploy/vps/.env`, `LHC_TELEGRAM_BOT_TOKEN`).

Схема входа (v3, тикеты): владелец вносит @username → человек открывает бота,
жмёт /start (ID фиксируется, предзаявка закрывается сама) → бот присылает
кнопку «🎭 Открыть Studio» с персональной ссылкой (одноразовый тикет, 90 сек) →
в браузере один клик «Войти в мастерскую» → Studio. Никаких ручных кодов.

## 1. Вход владельца
1. В боте (аккаунт владельца) нажать «🎭 Открыть Studio» → приходит персональная ссылка.
2. Открыть ссылку в браузере → страница показывает «Войти в мастерскую».
3. Нажать «Войти» → ожидается: открывается Studio.
4. В боте — меню владельца («Добавить участника», «Участники»,
   «Отозвать доступ», «Открыть Studio»).

## 2. Вход отдельного участника
1. Владелец в боте: «Добавить участника» → @username человека (числовой ID
   знать не нужно; если человек уже писал боту — права привяжутся к его ID сразу).
2. Человек открывает ссылку на бота, жмёт `/start` → приветствие + кнопка
   «🎭 Открыть Studio» с персональной ссылкой.
3. Человек открывает ссылку в браузере, жмёт «Войти» → ожидается: вход в Studio.

## 3. Неизвестный пользователь
1. Человек НЕ из списка пишет боту `/start`.
2. Ожидается: понятное сообщение («доступ по приглашению, заявка отправлена»),
   владельцу приходит запрос с кнопками «Разрешить/Отклонить».
3. «Разрешить» → человеку сразу уходит персональная ссылка, вход как в п.2.
   «Отклонить» → внятный отказ.

## 4. Повтор ссылки
1. Использованную ссылку `…/?ticket=…` открыть повторно / переслать другому.
2. Ожидается: «ссылка недействительна», сессия не выдаётся. Новая ссылка —
   только кнопкой «🎭 Открыть Studio» в боте допущенного пользователя.

## 5. Вход без бота
1. Открыть `https://…:8741/` без тикета → ожидается: объяснение и кнопка
   «Открыть бота в Telegram», прямого входа со страницы нет.

## 6. Отзыв активной сессии
1. Участник внутри Studio. Владелец в боте: «Отозвать доступ» → человек.
2. Ожидается: следующая загрузка Studio у участника ведёт на страницу входа;
   его неиспользованные ссылки тоже мертвы. Повторный вход — через бота
   после повторного добавления (закрытие браузера само по себе требует нового
   «Открыть Studio» в боте, но не нового приглашения, пока права действуют).

Отметить результат каждого пункта (дата, кто проверял) — до закрытия B13.
